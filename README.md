# 保單工具書助手｜同仁安裝包下載

這裡提供 NotebookLM 保單工具書助手 **0.2.8** 的 Chrome 未封裝擴充功能安裝包。

## 下載正確的檔案

1. 開啟 [0.2.8 版本頁](https://github.com/kahill3131/notebooklm-insurance-guide-downloads/releases/tag/v0.2.8)。
2. 在 **Assets** 區下載 `notebooklm-insurance-guide-v0.2.8.zip`。
3. 不要下載 GitHub 自動列出的 **Source code (zip)** 或 **Source code (tar.gz)**；它們不是擴充功能安裝包。

安裝 ZIP 的 SHA-256：`5F38AC3F0FCB1270B90C25F2FDB23EFCE7725A18D8FD31D8453F3678F5703C19`

## 安裝

解壓 ZIP，找到內含 `manifest.json` 的 `保單工具書助手` 資料夾。用電腦版 Chrome 開啟 `chrome://extensions/`，開啟「開發者模式」，按「載入未封裝項目」，選取該資料夾。詳細的首次安裝及手動更新步驟，請看 ZIP 內的 `同仁安裝與手動更新.md`。

安裝包不含客戶文件；不要將客戶資料放進擴充功能資料夾。
