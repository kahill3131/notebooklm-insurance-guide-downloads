# NotebookLM 保單工具書助手 0.2.8

這是協助保險顧問操作 NotebookLM 的 Chrome 擴充功能。安裝後，NotebookLM 頁面會出現九步驟引導面板，協助你從原始保險建議書、保單分析，到製作客戶保障工具書簡報。工具負責引導操作；NotebookLM 產生的內容仍需自行核對。

## 下載安裝包

請到 [0.2.8 版本頁](https://github.com/kahill3131/notebooklm-insurance-guide-downloads/releases/tag/v0.2.8)，在 **Assets** 下載 `notebooklm-insurance-guide-v0.2.8.zip`。也可以[直接下載安裝 ZIP](https://github.com/kahill3131/notebooklm-insurance-guide-downloads/releases/download/v0.2.8/notebooklm-insurance-guide-v0.2.8.zip)。

請勿下載 GitHub 自動產生的 **Source code (zip)** 或 **Source code (tar.gz)**；它們不是擴充功能安裝包。

安裝 ZIP 的 SHA-256：`5F38AC3F0FCB1270B90C25F2FDB23EFCE7725A18D8FD31D8453F3678F5703C19`

## 快速安裝與啟用指南

1. 下載上面的安裝 ZIP，並先解壓縮。
2. 開啟電腦版 Google Chrome，在網址列輸入 `chrome://extensions/`。
3. 開啟右上角的「開發者模式」。
4. 按「載入未封裝項目」。
5. 選取解壓後的 **`保單工具書助手` 資料夾**；該資料夾內應直接看得到 `manifest.json`。
6. 開啟 [NotebookLM 官方網站](https://notebooklm.google.com/)，即可使用保單工具書引導面板。

ZIP 內另附 `同仁安裝與手動更新.md`，包含首次安裝與日後手動更新的詳細步驟。

## 9 步驟引導流程總覽

| 步驟 | 階段說明 | 核心動作 |
| :--- | :--- | :--- |
| **STEP 1** | 準備原始建議書 | 在 NotebookLM 建立筆記本並加入原始保險建議書來源。 |
| **STEP 2** | 加入「保單分析規則」 | 一鍵複製分析規則，透過 NotebookLM 左側「新增來源」→「複製的文字」貼上；面板會提示是否偵測到規則來源。 |
| **STEP 3** | 執行保單分析 | 人工確認來源勾選，帶入或複製分析指令；送出後再勾選確認。 |
| **STEP 4** | 分析結果轉為來源 | 將 NotebookLM 的分析結果儲存至記事，再選「轉換成來源」；左側出現第三筆來源後，面板顯示綠色狀態並解鎖下一步。來源檔名可以不同。 |
| **STEP 5** | 確認工具書來源 | 查看規則來源的即時提示，人工確認原始建議書與分析結果已勾選、分析規則未勾選後再繼續。 |
| **STEP 6** | 選擇視覺風格 | 選擇預設、插畫或商務等風格，也可以填寫自訂風格。 |
| **STEP 7** | 複製工具書生成指令 | 將選定的視覺風格帶入簡報指令；複製成功後進入下一步。 |
| **STEP 8** | 開啟簡報並生成 | 在 NotebookLM 開啟簡報彈窗，貼上指令並生成；彈窗開啟後不要再點引導面板。 |
| **STEP 9** | 最後確認 | 核對來源與風格，按「完成並縮小」後，面板變成側邊小球。 |

## 特殊貼心功能

1. **側邊小球**：點面板右上角「−」可縮成約 40px 的圓鈕，平時半藏於側邊，滑鼠靠近會滑出。可以拖曳調整高度或換邊；點小球或 Chrome 工具列圖示即可展開。
2. **指令帶入與複製備援**：點「帶入指令」時，工具會嘗試找到 NotebookLM 輸入框並填入，同時備份到剪貼簿；若頁面改版影響自動填入，可手動貼上。
3. **進度自動記憶**：目前步驟與選取的風格會保留。更新或重新載入擴充功能後，請重新整理已開啟的 NotebookLM 分頁。

安裝包不含客戶文件；請勿把客戶資料放入擴充功能資料夾。
